# Hotel Booking Analysis & Cancellation Insights

## Project Overview
An Exploratory Data Analysis (EDA) project analyzing hotel booking data to identify booking trends, cancellation patterns, and factors associated with booking value.

## Objectives
- Analyze booking patterns across City Hotels and Resort Hotels.
- Investigate hotel booking cancellations.
- Explore the relationship between lead time and cancellation rates.
- Analyze length of stay and average daily rate (ADR).

## Tools & Technologies
- Python
- Pandas and NumPy
- Seaborn
- Jupyter Notebook

## Key Insights
- Approximately 37% of bookings were cancelled.
- City Hotels accounted for approximately 66% of all bookings.
- Longer booking lead times were associated with higher cancellation rates.
- Total nights stayed showed a strong relationship with calculated booking value.

## Project Structure
- `hotel_bookings.ipynb` — Data cleaning, exploratory analysis, visualizations, and insights.
- `hotel_bookings.csv` — Dataset used for analysis.

## How to Run
1. Clone this repository.
2. Install the required Python libraries.
3. Open `hotel_bookings.ipynb` in Jupyter Notebook.
4. Update the dataset path if necessary and run the notebook cells.

## Conclusion
This project demonstrates how exploratory data analysis can help identify hotel booking trends and cancellation patterns to support data-driven decision-making.
